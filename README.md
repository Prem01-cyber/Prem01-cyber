solutions that are practical, well-designed, and genuinely useful. My focus areas:

- **Web Development** — full-stack applications with clean, accessible interfaces
- **Cybersecurity** — network and data security, secure-by-design systems
- **AI / ML** — applied models for real-world problems

Currently exploring advanced ML algorithms, modern security practices, and the intersection of
quantum computing with AI and cryptography.
